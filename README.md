# Hack-Corruption Backend

Welcome to the backend portion of the Hack-Corruption project. This project aims to provide a platform for reporting and tracking corruption cases. The backend is built using Node.js, Express, and MongoDB.

## Features

- 🔐 **User Authentication and Management**: Securely manage user accounts and authentication.
- 📝 **Report Corruption Cases**: Easily report corruption cases with detailed information.
- 📊 **Track Report Status**: Monitor the status of reported cases in real-time.
- 🌟 **Success Stories**: Share and view success stories of resolved cases.
- 🤖 **AI Integration for Image Analysis**: Utilize AI to analyze images related to corruption cases.
- 🛠️ **Admin Dashboard**: Comprehensive dashboard for administrators to manage the platform.

## Installation Guide

1. **Clone the repository:**
    ```bash
    git clone https://github.com/your-repo/hack-corruption-backend.git
    cd hack-corruption-backend
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```

3. **Set up environment variables:**
    Create a `.env` file in the root directory and add the following:
    ```env
    PORT=3000
    MONGO_URL=your_mongodb_connection_string
    GEMINI_API_KEY=your_google_generative_ai_key
    ```

4. **Run the server:**
    ```bash
    npm start
    ```
